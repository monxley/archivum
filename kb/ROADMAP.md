# ARCHIVUM: план наполнения

**Приоритет — история религий**: Ханаан и Израиль, происхождение Яхве, боги → демоны, история текста Библии, «переупакованные» боги (партии N1–N3).

Цель: собрать в одну карту связей все конспирологические теории, эзотерику, мифы, священные тексты и археологические находки. База пополняется ночными сессиями, по одной партии за ночь.

## Правила для каждой ночной партии

1. Взять первый невыполненный пункт из списка ниже (или два, если они маленькие).
2. Добавить 40–80 новых узлов в нужный `kb/data/<домен>.json`. Новый домен заводится как новый файл; его нужно также добавить в `DOMAINS` в `kb/build.py`.
3. У каждого нового узла должно быть не меньше 3 связей, и хотя бы одна из них ведёт в **другой** домен. Ради этого и строится карта.
4. Пройтись по старым узлам и добавить обратные связи туда, где они явно напрашиваются.
5. Статусы ставить по научному консенсусу, а не по популярности теории. Фальсификации (например, «Протоколы») описываются как фальсификации, с фактами о том, как это доказано.
6. Запустить `python3 kb/build.py`. Висячих ссылок должно стать меньше или они должны остаться на нуле. Собранный сайт лежит в `docs/`.
7. Отметить пункт в этом файле, дописать строку в журнал внизу, закоммитить и запушить.

Формат узла (одна строка на узел):

```json
{"id":"kebab-id","t":"Название","en":"English name","era":"~1500 до н.э.","y":-1500,"s":"fact|disputed|debunked|hoax|belief|hypothesis","sum":"1–3 предложения","ref":"первоисточник: стих, надпись, табличка, научная работа","tags":["…"],"l":[["other-id","src|comp|over|anti"]]}
```

Поле `ref` обязательно для тем истории религий и желательно для остальных: оно выводится в досье как «Источник». Библейские ссылки по синодальной нумерации, при расхождении — обе: «Пс 81 (82)».

Типы связей: `src` — «опирается на / выросло из» (направленная), `comp` — «дополняет», `over` — «пересекается» (общий мотив, символ, персонаж), `anti` — «опровергает» (направленная).
