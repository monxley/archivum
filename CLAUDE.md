# ARCHIVUM — правила работы

**Основной репозиторий проекта: github.com/monxley/archivum.** Прежний репозиторий `monxley/new-crypto` больше не используется для разработки.

## Устройство

- `kb/data/*.json` — данные: один файл на домен, один узел на строку.
- `kb/build.py` — проверка и сборка (`python3 kb/build.py`, нужен numpy). Пишет `index.html`, `app.js`, `data.js` в корень репозитория.
- `kb/web/` — исходники страницы (`index.html` без doctype-обёртки, `app.js`).
- `kb/ROADMAP.md` — очередь партий наполнения, правила узла и журнал.
- Корень `main` публикуется GitHub Pages: https://monxley.github.io/archivum/

## Процесс

- В `main` напрямую не пушить. Работа идёт в ветке `nightly`; изменения попадают на сайт через pull request `nightly → main`, который сливает владелец.
- Перед коммитом: `python3 kb/build.py` без ошибок и без висячих ссылок; собранные файлы в корне коммитятся вместе с данными.
- Статусы узлов — по научному и историческому консенсусу; только проверяемые факты; источник в поле `ref`, где возможно.
- Рабочие и служебные материалы владельца (стратегии, черновики каналов) в этот публичный репозиторий не кладутся.
