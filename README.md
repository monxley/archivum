# ARCHIVUM

Карта связей между конспирологическими теориями, эзотерикой, мифами, священными текстами и археологическими находками.

**Сайт:** https://monxley.github.io/archivum/

У каждого узла есть статус по научному и историческому консенсусу (доказано, спорно, опровергнуто, подделка, вера, гипотеза) и, где возможно, первоисточник. База пополняется партиями.

Сайт статический: `index.html`, `app.js`, `data.js`, без внешних библиотек. Данные и сборка — в папке `kb/` (`python3 kb/build.py`), план наполнения — `kb/ROADMAP.md`.
